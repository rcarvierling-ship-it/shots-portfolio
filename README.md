# shots-portfolio

Static sports photography portfolio for Reese Vierling, served at
https://portfolio.rcv-media.com/. Plain HTML, no build step.

- `index.html` — the whole site (styles and script inline)
- `photos/manifest.json` — the photo list; each id has `-640`, `-1280` and `-2000` JPEGs
- `og.jpg`, `favicon.svg` — share image and icon

Deploy on Vercel with Framework Preset "Other" and no build command.
